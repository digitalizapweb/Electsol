# Elecsol

Sitio web de Elecsol, servicios eléctricos profesionales: instalaciones, proyectos, soluciones solares y certificaciones SEC.

Sitio estático (HTML, CSS y JavaScript con Bootstrap 5) publicado en Vercel.

- `index.html`: contenido de la página
- `css/styles.css`: estilos
- `js/index.js`: menú, contadores y visor de fotos
- `img/trabajos/`: fotos de trabajos realizados (versión grande y `-sm` para miniaturas)
